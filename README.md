# Nerdy Popcorn for Windows

Official Windows installers and release checksums for Nerdy Popcorn.

Download and installation: https://nerdypopcorn.ca/windows.html

This repository contains public release assets and third-party notices only. The application source and customer data are not published here.

Windows releases include Java and VLC. Enter the activation code from your Nerdy Popcorn website setup when opening the app. Nerdy Popcorn does not provide streaming content.

Installers are unsigned unless a release explicitly states otherwise. Exact SHA-256 checksums and the matching VLC source archive accompany each release.
